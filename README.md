# Personal Expense Tracker

## Day 5 - Delete Expense by ID

- Add multiple expenses
- View all expenses
- Delete an expense by ID
- Automatic IDs and basic input validation

Expenses are stored in memory and are cleared when the program exits.

## Run

```bash
javac -d out src/main/java/com/expense/model/Expense.java src/main/java/com/expense/Main.java
java -cp out com.expense.Main
```
